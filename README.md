# Meditación, 8 semanas

App de seguimiento de meditación: calendario, temporizador con campana, plan de 8 semanas y una guía para aprender a meditar.

Es un único archivo (`index.html`) sin build ni backend. El progreso se guarda en `localStorage`, en el navegador de quien la usa — cada dispositivo lleva su propio historial, no se sincroniza entre navegadores.

## Publicar en GitHub Pages

1. Subí `index.html` a la raíz de un repositorio (o a `/docs` si preferís).
2. En el repo, andá a **Settings → Pages**.
3. En **Source**, elegí la rama y la carpeta donde está el archivo (por ejemplo `main` / `/root`).
4. Guardá. GitHub te va a dar una URL tipo `https://tu-usuario.github.io/tu-repo/` en uno o dos minutos.

No hace falta ningún paso de instalación ni `npm install`.
